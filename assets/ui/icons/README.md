# Icon UI có thể thay trực tiếp

Toàn bộ icon HUD chính nằm trong thư mục này. Có thể thay từng file bằng SVG/PNG/WebP cùng tên, hoặc đổi đường dẫn trong `assets/ui/ui-icons.js`.

Kích thước khuyến nghị: icon thường 128x128, ảnh đại diện 256x256, nền trong suốt. Giữ vùng an toàn 10% quanh mép để icon không bị cắt trên điện thoại.

Các tên đang dùng: `portrait.svg`, `pet.svg`, `artifact.svg`, `coin.svg`, `jade.svg`, `auto.svg`, `report.svg`, `challenge.svg`, `quick-battle.svg`, `gear.svg`, `skill.svg`, `battle.svg`, `seal.svg`, `cultivate.svg`.
