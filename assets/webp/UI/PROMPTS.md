# Wuxia UI PNG assets

Generated with the built-in image_gen tool using Wuxia Hero’s Forest Battle (1).png as a style reference. PNGs preserve true alpha; trimmed and resized for runtime use.

- action-bar-frame.webp: isolated horizontal antique bronze-gold action bar, symmetric dragons at the ends, jade details, empty transparent center, no text or icons.
- panel-frame.webp: square bronze-gold minimap/dialogue frame, compact dragon and cloud corners, empty transparent center, no labels or map.
- portrait-frame.webp: circular bronze-gold portrait ring, dragon wrapping the left edge, jade accent, transparent portrait opening, no face or text.

Runtime layout and live text are HTML/CSS; decorative assets are PNG. Original generations remain in the Codex generated_images folder.
