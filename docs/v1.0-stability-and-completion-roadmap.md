# Vạn Tiên Lục v1.0 — Stability and Completion Roadmap

## Implemented in this branch
- AFK reward normalization and 12-hour hard clamp.
- Save-compatible skill progression (levels 1–5 per skill).
- Skill upgrade economy: each next rank costs 180 × rank silver and 12 × rank spirit; damage increases 12% per rank and MP cost decreases 2.5% per rank.
- Five-stage solo dungeon with escalating waves and a final boss encounter; 20 spirit entry cost and completion rewards.
- Equipment affixes for critical chance, critical damage, penetration and attack speed; derived stats are recalculated when equipping/unequipping and affixes are persisted with inventory snapshots.
- Existing save key and snapshot version remain unchanged; new fields are optional for older v3 saves.

## Remaining release work
### P0 Reliability
- Run TypeScript/Vite build and automated tests in a local/CI environment.
- Test v2/v3 save migration and gear affix restoration with representative real saves.
- Add export/import backup and visible save status.

### P1 Progression and combat
- Simulate time-to-level and time-to-breakthrough across all 36 stages using actual reward sources before changing the current level curve.
- Add distinct boss telegraphs and attack patterns with playtested counterplay; current HP phases still use stat escalation.
- Add dungeon retry/exit controls and test defeat/reset behavior.
- Add skill unlock requirements and branch choices; current skill ranks are linear upgrades.

### P2 Equipment and retention
- Add equipment refinement tiers, crafting recipes, set bonuses and drop-table expected-value simulation.
- Add daily/weekly dungeon objectives and battle recap.

### Backend-gated systems
Cloud saves, accounts, anti-cheat, multiplayer, guild/sect chat, arena matchmaking, cross-server rankings and payment require a backend, security rules and operational infrastructure. They must remain unavailable until that exists.

## Acceptance
A release candidate requires a successful `npm run build`, save migration QA, AFK claim-once QA, dungeon completion/failure QA, equipment affix restore/equip QA, skill rank persistence QA and mobile viewport smoke tests.
