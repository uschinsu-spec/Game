# Vạn Tiên Lục v1.0 — QA Checklist

## Build and persistence
- [ ] Run `npm run balance:simulate -- 5`, `-- 10` and `-- 20`; review progression sensitivity.
- [ ] `npm ci`
- [ ] `npm run build`
- [ ] Load legacy v2 and current v3 saves.
- [ ] Verify old v3 snapshots without skillLevels load with every skill at rank 1.
- [ ] Save/reload upgraded skills and confirm levels, damage multipliers and MP costs.
- [ ] Save/reload equipment with every affix and confirm derived stats are not double-counted.

## AFK
- [ ] 59 seconds grants no reward; 60 seconds grants 5 EXP and 4 silver.
- [ ] 8 minutes grants 40 EXP, 32 silver and 1 spirit.
- [ ] Oversized and non-finite elapsed values are clamped safely.
- [ ] Visibility changes and reloads never claim the same interval twice.

## Skill progression
- [ ] Upgrade costs use next rank × 180 silver and × 12 spirit.
- [ ] Insufficient resources do not change rank or consume currency.
- [ ] Ranks stop at 5.
- [ ] All four skills and ultimate restore rank after reload.
- [ ] Skill casts retain cooldown and MP checks.

## Equipment
- [ ] Weapon critical damage and penetration affixes change combat stats.
- [ ] Accessory critical chance and attack speed change combat stats.
- [ ] Unequip removes only that item's bonuses.
- [ ] Replacing an item subtracts old bonuses before applying new bonuses.
- [ ] Legacy items without affix fields behave as zero-affix items.

## Dungeon
- [ ] Entry costs exactly 20 spirit; insufficient spirit cannot enter.
- [ ] Repeated entry while active is rejected and refunded.
- [ ] Four progressive stages lead to a boss stage.
- [ ] Clearing final stage grants completion rewards once.
- [ ] World waves resume after completion.
- [ ] Defeat/respawn during dungeon does not duplicate completion rewards.

## Responsive/runtime
- [ ] Portrait 320×640, 360×800, 390×844, 430×932.
- [ ] Landscape resize keeps HUD accessible.
- [ ] x1/x2/x3 combat and long-session memory/performance smoke tests.
