# Vạn Tiên Lục v1.0 — QA Checklist

## Automated checks
- [ ] `npm ci`
- [ ] `npm run build`
- [ ] Add/run unit tests for save migration and AFK reward calculations when a test runner is introduced.

## AFK and persistence
- [ ] Fresh profile starts with the expected initial stats and resources.
- [ ] Existing v2 save migrates realm index and retains inventory/equipment/claims.
- [ ] Existing v3 save restores stats, resources, cultivation EXP, inventory, equipment and realm.
- [ ] Malformed JSON or unavailable localStorage does not crash game startup.
- [ ] 59 seconds offline grants no reward.
- [ ] 60 seconds offline grants 5 character EXP and 4 silver.
- [ ] 8 full minutes offline grants 40 character EXP, 32 silver and 1 spirit stone.
- [ ] Offline reward calculation never exceeds 12 hours, even if called with Infinity or a very large duration.
- [ ] Background/foreground cycles do not grant the same hidden interval twice.
- [ ] Reload after a claim does not replay the already-claimed interval.
- [ ] Toast says character EXP, not cultivation EXP.

## Progression and combat
- [ ] Character EXP levels up correctly and stops at level 100.
- [ ] Cultivation EXP is only increased by cultivation-specific rewards/actions.
- [ ] Realm breakthrough validates all costs before consuming any resources.
- [ ] Boss phase transitions occur once at each configured threshold.
- [ ] Boss guaranteed core drop occurs once per boss kill.
- [ ] Skill cooldown and MP validation cannot be bypassed by manual cast calls.
- [ ] Death/respawn does not allow stale projectiles to damage the player.

## Responsive and runtime
- [ ] Portrait: 320×640, 360×800, 390×844 and 430×932.
- [ ] Landscape resize does not leave HUD or world elements off-screen.
- [ ] Tab hidden for 1 minute, restored, then hidden again: each interval is counted once.
- [ ] Long session at x1, x2 and x3 does not create runaway timers or duplicate listeners.
- [ ] No missing character, monster or skill asset requests.
